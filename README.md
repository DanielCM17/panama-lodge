# Panama Lodge landing page

A responsive, single-page hospitality website concept for Panama Lodge in Livingstone, Zambia.

## Preview locally
Open `index.html` in a modern browser. Tailwind CSS is loaded from its CDN, so an internet connection is needed for the styles.

## Included
- Hero, tours and experiences, rooms, pricing, about, CTA, contact, footer
- Responsive mobile navigation
- Enquiry form that prepares an email draft (not a live booking backend)
- Local image assets cropped from an AI-generated visual concept

## Before publishing
- Confirm actual room categories, prices, amenities, tour availability and package inclusions.
- Replace the illustrative image crops with approved high-resolution lodge photography.
- Add the lodge's real telephone/WhatsApp, email, and precise address.
- Connect the form to a real booking/enquiry backend or the lodge's email address.
- Confirm permission to use the Panama Lodge name and brand assets.
